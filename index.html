01

แนวคิดของ K-Means

K-Means เป็นอัลกอริทึมแบบ Unsupervised Learning สำหรับแบ่งข้อมูลที่ไม่มีป้ายกำกับ (Unlabeled Data) ออกเป็น K กลุ่ม โดยต้องการให้ข้อมูลในกลุ่มเดียวกันมีความคล้ายคลึงกัน และลดความแปรปรวนภายในกลุ่ม หรือ Within-Cluster Sum of Squares (WCSS)

07

Iteration 2 — Convergence Check

ใช้ Centroid ใหม่ C₁ = 3 และ C₂ = 12 จัดข้อมูลซ้ำ

ข้อมูล 2 และ 4

2 → |2−3| = 1 < 10 → Cluster 1

4 → |4−3| = 1 < 8 → Cluster 1

ข้อมูล 10, 12 และ 14

10 → 2 < 7 → Cluster 2

12 → 0 < 9 → Cluster 2

14 → 2 < 11 → Cluster 2

Convergence: สมาชิกของแต่ละ Cluster ยังคงเหมือนเดิม และ Centroid ไม่เปลี่ยนแปลง จึงยุติการทำงานของอัลกอริทึม

09

WCSS — Within-Cluster Sum of Squares

ใช้วัดความกระจายของข้อมูลภายในแต่ละ Cluster จาก Centroid ของกลุ่ม

WCSS₁ = (2−3)² + (4−3)² = 2
WCSS₂ = (10−12)² + (12−12)² + (14−12)² = 8

สรุปการทำงาน

Initialize → Assign → Update → Repeat → Convergence

จากตัวอย่าง K-Means ที่กำหนด K = 2 ข้อมูลถูกแบ่งออกเป็น 2 กลุ่มอย่างชัดเจน หลังจาก Update Centroid แล้วทำการ Assign อีกครั้ง พบว่าสมาชิกของแต่ละกลุ่มไม่เปลี่ยนแปลง จึงถือว่า Algorithm Converged และได้ผลลัพธ์สุดท้ายเป็น Cluster 1 = {2,4} และ Cluster 2 = {10,12,14}
